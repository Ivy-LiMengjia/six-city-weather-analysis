
# Six-City Weather Data Analysis (1945–2024)

## Project Overview
This academic group project explores historical weather patterns across six cities from 1945 to 2024 using Python. The analysis focuses on temperature, humidity, and precipitation, comparing long-term trends and differences between cities.

## Cities Analysed
- Newcastle, United Kingdom
- Budapest, Hungary
- Sydney, Australia
- Cairo, Egypt
- São Luís, Brazil
- Vancouver, Canada

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Cartopy
- Open-Meteo Historical Weather API

## Analysis
The project includes:
- Collecting and cleaning historical weather data
- Calculating annual and decadal summary statistics
- Visualising temperature, humidity, and precipitation trends
- Comparing weather patterns across six cities
- Mapping geographical differences in weather conditions
- Comparing the earliest and latest ten-year periods

## Key Findings

- **Temperature:** All six cities experienced an increase in average temperature between 1945–1954 and 2015–2024. Vancouver recorded the largest increase (approximately 1.40°C), while São Luís had the smallest (0.33°C).

- **Precipitation:** Changes varied considerably across cities. Vancouver experienced a decrease of approximately 672 mm in average annual precipitation, while São Luís and Sydney recorded increases of approximately 409 mm and 326 mm, respectively.

- **Humidity:** Average relative humidity increased in five of the six cities. Sydney recorded the largest increase (3.47 percentage points), while Vancouver experienced a slight decrease.

- **Regional Differences:** During 2015–2024, São Luís had the highest average annual precipitation (approximately 2,213 mm), while Cairo had the lowest (approximately 33 mm).
