
# Six-City Weather Data Analysis (1945–2024)

## Project Overview
This academic group project explores historical weather patterns across six cities from 1945 to 2024 using Python. The analysis focuses on temperature, humidity, and precipitation, comparing long-term trends and differences between cities.

## Cities Analysed
- Newcastle, United Kingdom
- Budapest, Hungary
- Sydney, Australia
- Cairo, Egypt
- São Luís, Brazil
- Vancouver, Canada

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Cartopy
- Open-Meteo Historical Weather API

## Analysis
The project includes:
- Collecting and cleaning historical weather data
- Calculating annual and decadal summary statistics
- Visualising temperature, humidity, and precipitation trends
- Comparing weather patterns across six cities
- Mapping geographical differences in weather conditions
- Comparing the earliest and latest ten-year periods

## Project Files
- `groupwork- weather.ipynb` — Jupyter Notebook containing the Python code, analysis, and visualisations.

## Data Source
Historical weather data was obtained from the [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api).
